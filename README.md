# Project-1-The-Imitation-Game
### Game Rules:
1. Two humans join, one being the interrogator, and one being the respondent.
2. The game randomly assigns the human respondent and AI to anonymous labels x and y.
3. The interrogator asks x and y questions through text chat.
4. X and Y answer without revealing which is human.
5. The interrogator guesses which label is the AI.
6. The game then reveals the identities and whether the guess was correct.
